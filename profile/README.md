## 关于 ScriptForge 组织

ScriptForge 是一个专注于 **C++ 开发**的开源组织，由热爱编程的中学生开发者创立。
本组织致力于打造**轻量、高效、实用**的 C++ 工具库与桌面应用，持续探索现代 C++ 技术的更多可能性；同时记录个人技术成长历程，免费分享开源成果。

组织秉持「简单实用、持续迭代、开放共享」的开发理念，所有项目完全开源可自由复用，既适合 C++ 初学者参考学习，也可直接应用于实际开发场景，帮助开发者提升开发效率。

## 组织核心项目
以下为本组织旗下开源项目，长期持续维护更新，欢迎 Star、Fork 与代码贡献 🌟

- **Scriptforge**（[仓库链接](https://github.com/ScriptForge6/Scriptforge)）  
基于 C++23 构建的通用基础工具库，封装高频通用功能，简化日常开发流程。

- **HideWindow**（[仓库链接](https://github.com/ScriptForge6/HideWindow)）  
基于 C++ + Qt + Win32 API 开发的桌面窗口管理工具，支持快速隐藏、后台管控窗口，项目持续迭代完善中。

- **novel_writer**（[仓库链接](https://github.com/ScriptForge6/novel_writer)）  
基于 AI 驱动&编写的自动化小说写作工具，目前尚未完成测试，仅供体验与学习使用。

## 贡献指南
欢迎所有热爱 C++、喜欢开源的开发者参与共建，一同完善项目、共同进步：
1. Fork 本组织下对应目标仓库
2. 新建功能/修复分支（`feature/xxx` / `bugfix/xxx`）
3. 规范编写代码，保证注释清晰、风格统一
4. 提交 Pull Request，清晰描述修改内容与实现目的
5. 等待审核通过后，合并至主分支
