## About ScriptForge Organization
ScriptForge is an open-source organization focused on **C++ development**, founded by a student developer with a passion for programming.

We are committed to building **lightweight, efficient and practical** C++ utility libraries and desktop applications, continuously exploring more possibilities of modern C++. Meanwhile, we document the journey of technical growth and share open-source achievements for free.

Adhering to the development philosophy of *Simplicity & Practicality, Continuous Iteration, Open Sharing*, all projects are fully open-source and reusable. They are suitable for C++ beginners to learn and reference, and can also be directly applied to actual development scenarios to improve development efficiency.

## Core Projects
Below are our open-source projects under long-term maintenance and iteration.
Star, Fork and Contributions are highly welcomed 🌟

- **Scriptforge** ([Repository](https://github.com/ScriptForge6/Scriptforge-xmake)[Repository(old)](https://github.com/ScriptForge6/Scriptforge))  
A general-purpose utility library built on C++23, encapsulating commonly used functions to accelerate daily development.

- **HideWindow** ([Repository](https://github.com/ScriptForge6/HideWindow))  
A desktop window management tool developed with C++ + Qt + Win32 API. It supports quick window hiding and background management, with ongoing optimization and updates.

- **novel_writer** ([Repository](https://github.com/ScriptForge6/novel_writer))  
An AI-powered automatic novel writing tool. Not fully tested for now, only for learning and experimental use.

## Contribution Guidelines
All C++ enthusiasts and open-source lovers are welcome to join and co-build projects:
1. Fork the target repository under our organization
2. Create a new branch (`feature/xxx` / `bugfix/xxx`)
3. Write standardized code with clear comments and unified code style
4. Submit a Pull Request with clear descriptions of modifications and purposes
5. Wait for review and merge to the main branch after approval
